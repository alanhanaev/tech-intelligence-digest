# Tech Intelligence Digest

Production configuration for a recurring AI / engineering / developer-job-market intelligence digest.

Files:
- `PROMPT.md` — production behavior and output rules.
- `SOURCES.yaml` — curated source families and access strategy.
- `SETTINGS.yaml` — tunable lookbacks, priorities, and counts.
- `CHANGELOG.md` — configuration history.

Planned cadence:
- Daily: 19:00 Europe/Belgrade
- Weekly: Sunday 19:00 Europe/Belgrade

The configuration intentionally separates:
- fast-changing news/events;
- practical `AI Workflow & Lifehacks`, which uses a longer ~30 day discovery window.
